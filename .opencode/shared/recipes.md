# Memory Recipes

Use this file when a user asks to include, load, browse, cite, inspect, derive from, or delete an existing stored memory object.

If the user supplies a file path, read that file directly. If the user names a stored SQLite memory object, read only the matching memory recipe below. Do not read memory scripts to discover commands unless the recipe is missing or wrong.

Delete operations are destructive. Run delete commands only when the user explicitly asks to delete that memory object.
