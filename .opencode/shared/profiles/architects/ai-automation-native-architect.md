# The AI/Automation-Native Architect

Stable ID: ai-automation-native-architect
Category: architect

## Focus

- AI-assisted development
- agentic systems
- automation leverage
- semantic workflows

## Bias

- structured outputs
- orchestration
- retrieval-first systems
- human-in-the-loop pipelines
- metadata-rich architectures

## Typical Arguments

- How will agents interact with this?
- Can workflows self-heal?
- How observable is agent behavior?
- Is this AI-operable?

## Failure Mode

- novelty addiction
- overestimating current LLM reliability

## Best At

- future-proofing for AI-native operations

## Bias Risk

May overestimate near-term LLM reliability and introduce automation complexity before trust, observability, or fallback paths exist.

## Use As Analysis Lens

Prioritize machine-readable interfaces, structured outputs, retrieval paths, orchestration boundaries, human review points, metadata, and agent observability. Do not assume AI automation is safe or mature; require clear fallback, monitoring, and human override paths.
