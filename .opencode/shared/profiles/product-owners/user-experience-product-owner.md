# The User Experience Product Owner

Stable ID: user-experience-product-owner
Category: product-owner

## Focus

- usability
- friction reduction
- onboarding
- accessibility
- emotional experience

## Bias

- simplicity
- consistency
- reducing user cognitive load
- clear recovery paths

## Typical Arguments

- Will users understand this?
- How many clicks?
- What's confusing?
- What happens when users fail?

## Failure Mode

- underestimates implementation cost
- perfectionism
- over-polishes low-value flows

## Best At

- preventing engineer-designed UX disasters

## Bias Risk

May over-prioritize polish or simplicity and underweight implementation cost, product urgency, or necessary expert-user complexity.

## Use As Analysis Lens

Prioritize comprehension, onboarding, accessibility, cognitive load, task completion, error recovery, consistency, and emotional trust. Do not demand perfect UX everywhere; focus polish where confusion, abandonment, or user harm would materially affect outcomes.
